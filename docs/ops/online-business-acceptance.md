# rc.2 首批线上 Agent 验收执行包

2026-09-28：执行包已完成本地验证和线上只读预检查，尚未获得本批次供应商请求额度，未提交业务。总任务保持 `in_progress`。

## 本批次范围

复用 `scripts/staging_smoke.py::run_staging_smoke`，仅运行一次固定的合成 TXT 上传、队列解析、Agent HTTP 受理、Worker → MCP stdio → 检索、草稿产物下载与 SHA/引用检查。新增私有适配器限制 HTTP、目标 origin、执行次数和总时限；随后核对非空派发账本、原周期的一次消费、同键重放和状态读取后的账本不变。没有复制 Agent 或解析业务逻辑。

样本为 109 字节，SHA-256 `601d780a0cf011e03b7bf76465565802fd75850d201648bf4573ff0b317cf648`，内容只陈述合成合同的证据保留期为三十天，不含客户资料。问题固定为询问该保留期。真实解析器确认一个文本块。仅创建一个 `question_answer` 任务，`publishRequested=false`；不审批、发布产物或手工重试 Job。

本批次使用既有 pilot 企业和既有有效成员，通过已有 staging-only JWT 工具在 API Pod 内存中签发凭据。它验证实际认证 HTTP，但不证明交互式 GitHub OAuth。现有企业不是空容量测试企业；此次按新操作标识单独对账，不运行要求空企业的本地容量 CLI。

## 执行前检查与停止条件

1. 绑定 Namespace UID、四组 rc.2 不可变镜像、11 个关键运行源码哈希，以及 API/Worker/Consumer 的相关有效参数。默认命令只在本地验证包，`--preflight-readonly` 才连接已知 SSH 主机。
2. 只读核对 0031、成员有效、新键未出现、精确原 entitlement 和产品余额。周期必须仍有至少 35 分钟；计划于 **2026-09-29 18:20 北京时间**失效，原 pilot 18:57:59 到期，不自动延期。
3. `--execute` 需要与完整计划 SHA 和上述预算一致的新授权记录；在任何远端执行前排他、持久写入本地意图。没有授权、计划过期、源码漂移、旧意图或目标不符均拒绝。
4. 签名对象地址匹配完整 HTTPS origin，独立客户端不带 API bearer；关闭代理和重定向，拒绝非约定上传头。日志不保存凭据或签名 URL。
5. 成功须核验一个活动代次及块/向量、一个初始 Agent execution、真实 search/create_draft_artifact 工具记录、三类非空供应商记录、两项一次消费和下载产物 SHA。HTTP 200、任务受理或模型 responded 均不能单独算成功。

私有包位于原集中恢复组的 `online-business-acceptance-evidence`：`plan.private.json`、`execute_once.py`、`bounded_client.py`、`remote_body.py` 与边界测试。原源码按精确哈希从规范仓库加载，远端只经 stdin 在内存中运行，不创建远端恢复副本或 systemd 服务。所有新业务数据作为验收记录保留，不自动清理。
