## 本批次范围

复用 `scripts/staging_smoke.py::run_staging_smoke`，仅运行一次固定的合成 TXT 上传、队列解析、Agent HTTP 受理、Worker → MCP stdio → 检索、草稿产物下载与 SHA/引用检查。新增私有适配器限制 HTTP、目标 origin、执行次数和总时限；随后核对非空派发账本、原周期的一次消费、同键重放和状态读取后的账本不变。没有复制 Agent 或解析业务逻辑。

样本为 109 字节，SHA-256 `601d780a0cf011e03b7bf76465565802fd75850d201648bf4573ff0b317cf648`，内容只陈述合成合同的证据保留期为三十天，不含客户资料。问题固定为询问该保留期。真实解析器确认一个文本块。仅创建一个 `question_answer` 任务，`publishRequested=false`；不审批、发布产物或手工重试 Job。

本批次使用既有 pilot 企业和既有有效成员，通过已有 staging-only JWT 工具在 API Pod 内存中签发凭据。它验证实际认证 HTTP，但不证明交互式 GitHub OAuth。现有企业不是空容量测试企业；此次按新操作标识单独对账，不运行要求空企业的本地容量 CLI。
