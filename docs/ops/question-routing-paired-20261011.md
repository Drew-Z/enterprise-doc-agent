## 第三次失败：已知事实与证据缺口

密码候选请求派发1次，耗时7.398秒；HTTP状态200，采集器读取60,013字节，记录
`presales_invalid_model_output / stream_contract`及`invalidJson=true`。没有记录传输异常，
没有得到已解码回答、响应ID或用量。HTTP200本身不能证明模型调用成功。

旧采集器把具体`ModelResponseError`折叠为`invalidJson`，没有留下失败响应正文、内容类型
或具体解析错误。因此目前**无法确定根因**，不能归因于候选schema、上游网络、SSE格式、
流截断或结束标记；也不能据此说“密码语义判断失败”。未知用量不按0计费。

在停止真实调用后，本轮修复了诊断采集器：保存有界响应体SHA-256、是否为事件流的布尔值、
解析器错误码及重试属性、已经观察到的非负整数token计数。它不保存失败正文、推理文本、
供应商错误消息、HTTP头或凭据，不修补响应，也不改变生产重试行为。
新增控制测试覆盖缺少结束标记、非法事件、显式上游错误、错误内容类型和非流式非法JSON；
同时证明返回字节不变、只派发一次、私密测试文本不进入记录。
**修复只改善后续观测，不能追回本次丢失的细节。**
