## 本次超时与上一轮解析失败有何不同

本次设备请求的内层诊断回执为`waiting_headers / interrupted=true`；外层记录
`CancelledError / awaiting_response_headers`；gateway返回`presales_model_timeout`，
用时120.000秒。没有HTTP状态、响应正文、响应ID或token用量，候选输出解码未开始。

因此可以确认：**客户端时限到达前，底层transport尚未返回HTTP响应对象**。
`waiting_headers`仍是客户端观察边界，不能再推断为“已完成TCP/TLS和请求发送，只在排队”。
现有回执无法确认上游是否收到、执行、完成或计费；客户端取消也不证明供应商已取消处理。

[上一轮](./question-routing-paired-20261011.md)则收到HTTP200和60,013字节后发生流式

上一轮只是偶发网络问题、证明schema永远兼容，或把历史未知用量补成0。
