原三次无效模型输出只保留通用错误码，没有原始输出或拒绝类别，无法可靠还原其原因。本轮增加固定分类：响应 JSON/结构、输出不完整、不允许的响应、草稿 JSON/schema、定义原文、支持原文、支持组合、草稿约束、引用和流式协议。同步与后台执行把分类保存在既有 attempt provenance，主路失败后正常备用成功也保留主路分类。公开错误码、调用上限、重试/恢复条件、业务结算、用量和请求 ID 保持原契约；产品不新增保存原文、任意异常文本或密钥。
