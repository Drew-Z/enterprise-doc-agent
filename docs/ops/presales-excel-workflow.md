# 客户 Excel 问卷：导入、复核与原表回填

2026-10-09：已部署 staging rc.46（`9ed3857b361573b27abc9f6c245afb1dfdd9feaa`），数据库为 0035，并完成实际回退 rc.45 后重新发布。对应任务为 `presales-excel-workflow`，承接竞品分析中“客户问卷导入与原格式交付”的缺口。没有新增模型渠道，也没有改判历史商业验收。

## 使用

1. 在售前响应中新建响应表，填写名称，选择已就绪资料并确认适用范围。
2. 将“客户要求录入方式”改为“导入 Excel”，选择普通 `.xlsx` 文件。
3. 选择一个工作表、问题列、空白答案列和起止行。点击预览，逐项核对问题与答案格，勾选确认后保存。
4. 生成响应并逐条检查证据、条件和待补材料。超过 12 条时分页显示，每次提交下一批最多 12 条；失败行可单独重试，其他结果保留。
5. 下载“回填草稿 Excel”，或全部复核后下载“回填已复核 Excel”。详细引用、原稿及人工修订记录仍可通过现有 CSV 导出。

原文件、原始文件 SHA256 与确认后的映射保存在响应表中。刷新页面或从“我的响应表”重新打开后，无需再次上传。尚未收到保存成功时，请先查看最近响应表；再次明确提交相同意图时使用原幂等键。文件正文不写入浏览器持久存储。

## 支持边界

- 单文件最多 2 MiB、解压后最多 20 MiB，最多 20 个工作表、50,000 个实际单元格、10,000 行及 256 列。一次导入一个工作表范围中的 1–120 条非空文本问题，每条最多 2,000 字。演示会话仍受原更小限额约束。
- 每企业原始问卷另设 20 MiB 保存上限，属于 PostgreSQL 附件存储，不是文档摄入/向量索引；不增加文档处理量。原文件随响应表/租户保留及级联删除。当前文档存储用量卡不包含此独立上限；满额会明确拒绝新导入，不自动清理历史。
- 不支持宏、加密、数字签名、嵌入对象、外部链接及受保护模板。隐藏工作表/问题列、合并问题、公式问题、含答案/公式/合并/验证规则/表格或数组公式覆盖的目标格明确拒绝。损坏 ZIP/XML、重复单元格和异常展开范围拒绝。
- 保留其他工作表、样式、列宽、冻结窗格、原公式与其他 ZIP 成员。只回填选定答案格，以文字保存，字符串不会成为新公式。未完成或失败的行会在草稿中说明，不伪造答案。过长响应拒绝，不截断。
- 保留原排版和原公式，不在服务端重新计算公式。原表固定行高可能需要用户在 Excel 中调整才能看到完整多行答复。受控验证使用真实 XLSX 读写和浏览器下载后重新读取，未在原生 Excel 桌面应用中验收所有功能。
