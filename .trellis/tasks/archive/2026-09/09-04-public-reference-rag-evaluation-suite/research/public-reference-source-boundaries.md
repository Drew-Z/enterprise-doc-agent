# Public-reference source boundaries

## Purpose

This record supports a wholly fictional synthetic RAG evaluation corpus. It is not evaluation
evidence, a legal licensing opinion, or a claim that Northstar Ledger is real. Public material
informs scenario shape only; no source wording or source-specific terms are copied into corpus
files.

## Licensing boundary

The candidate OWASP licensing page could not be confirmed in this research pass: one candidate
returned HTTP 404, and the search provider returned a network error while seeking an
authoritative alternative. This task therefore copies no OWASP material. Any later proposal to
import source text must independently verify the applicable license first.

## Corpus construction rules

- All documents are newly written fictional Northstar Ledger text.
- Availability values, access duration, evidence fields, and roles are invented for test design.
- No real person, customer, employee, endpoint, credential, incident, contract, legal claim, or
  production metric is included.
- The corpus must not claim to implement or be certified by any reference organization.
- Source register and repository provenance stay adjacent to the dataset for future review.

## Evaluation boundary

The suite may exercise loader contracts, grounded-answer design, refusal contracts, and
indirect-injection labels. It cannot prove representative enterprise quality, provider
stability/revision/cost, production reliability/capacity, privacy/compliance, or M5/M7 closure.
A future real-provider run requires approved de-identified representative material, independent
semantic labels, stable route/revision evidence, cost data, repeatable clean runs, and explicit
gate review.
