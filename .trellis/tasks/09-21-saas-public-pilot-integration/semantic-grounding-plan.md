## Bug Analysis

1. Root cause category: Implicit Assumption / Test Coverage Gap。分类正确和引用逐字正确不证明正文含义正确；未证明完成也不等于证明未完成。
2. Why fixes failed: v5明确分类顺序，但把判断成立与交付正文写作并列，模型仍可在正确分类后写反关系；把unmet/unknown统一叫待完成会抹去认识状态差异。
3. Prevention: 保持模型输出原样，分别核验分类、正文、事实状态、必要出处及澄清，增加新领域资料；先记录事实再生成交付表述。白名单诊断只定位客户端边界，不从异常类推断供应商故障。
4. Expansion: 缺报告、有限条款优先级、多个已满足与未知前提并存、重复出现订单事实也需要单独出处。
5. Knowledge capture: 更新presales工作区与评测规范；本仓无Trellis模板副本，不新建无关目录。

固定4C4G、当前模型路由和时限；不改认证、不发邮件、不动客户记录/额度、不处理无关漏洞。新文件和临时资源逐项登记，历史脏文件/worktree保留。恢复组沿用 `presales-semantic-grounding` 阶段。
