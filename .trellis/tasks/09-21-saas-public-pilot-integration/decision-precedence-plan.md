## Bug Analysis

1. Root cause category: Missing Spec / Implicit Assumption。原提示词并列五类而没有明确冲突与硬限制的优先级；“未提供”被误读成能力不存在。H2-R6 同时引用冲突双方，H2-R5原文明确未知，因此不是召回丢失。
2. Why prior fixes failed: v3只解决引文；v4前提结构解决可选模块与启用状态，但未解决证据分类顺序。新增更多引用重复要求一度造成解码失败，已修复且不复活。
3. Prevention: 明确分类定义与顺序；冲突输出必须有澄清问题；真实单次生成验证；失败全保留。
4. Expansion: 合取需求中缺失要素不能被部分支持覆盖，明确已满足条件不重复列待办，优先条款只对指定范围生效。
5. Knowledge capture: 同步 presales-workspace / presales-quality 规范和报告，本仓无模板副本则不创建。
