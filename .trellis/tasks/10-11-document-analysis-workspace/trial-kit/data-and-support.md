# 数据、来源许可与支持边界

两套资料来自公开官网页面的本地文本快照，共同需求为明确的合成文件。公开可读不代表取得再发布许可，因此仅用于本地开发验证和受邀试用，不上传公开仓库、公开站点或第三方模型训练集。页面不是正式报价，价格、库存、地区和条款可能在抓取后变化。

试用者只上传所选资料包的 `upload/`。`reference/`、manifest、研究搜索摘要和原始抓取 JSON由观察者保管，不进入 Agent 上下文。若试用者改用自己的材料，必须先确认有权处理，并移除凭据、身份证明、商业秘密和不必要的个人信息。

当前候选未验证生产对象存储、正式身份链、4C4G 新工作负载容量或真实模型质量。试用组织者应提供环境 URL、测试账号、支持联系人、可用时段和停止时间；这些信息不得预填为本仓库的生产承诺。

问题报告至少包含匿名参与者编号、资料包、阶段、run ID、错误码和是否可恢复。不得提交 API key、登录口令、文档正文、模型隐藏推理或签名 URL。
