# 独立试用包

适用产品：企业多文档审阅与对比工作台。

目标是让没有参与开发的人独立完成一次“上传与分组 → 确认字段 → 运行 → 原文复核 → 人工修订/审核 → 导出 → 更新资料或参数”的完整任务，并留下可复核的时间、错误和退出记录。

试用材料：

- `../materials/validation-01/upload/`：首选软件采购任务。
- `../materials/holdout-football-01/upload/`：跨领域留出任务，用于扩大试用范围。
- `operator-guide.md`：参与者独立操作步骤。
- `timing-template.csv`：分阶段计时和结果分母。
- `feedback-form.md`：任务后反馈。
- `incident-and-supplement.md`：错误、补料和退出规则。
- `data-and-support.md`：数据边界、来源许可和支持方式。
- `acceptance-record-template.json`：观察者汇总，不得预填通过结论。
- `reviewer-guide.md`：候选运行完成后的独立答案复核流程；各包 `reference/review-notes.json` 仅为助手预审草稿。

观察者只负责提供访问、记录故障和回答环境问题，不能提示答案、替参与者修改结果或把参考文件交给系统。当前参与者为 0；本目录就绪只代表“内部验证与试用准备完成”，不代表独立 UAT、商业收益或付费意愿成立。
