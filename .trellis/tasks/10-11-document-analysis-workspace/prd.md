# 多文档审阅与对比工作台

日期：2026-10-11；实施记录更新：2026-10-13。状态：in_progress。A0–A4 本地工程候选和 A5 试用准备已完成内部验证；真实模型留出质量、4C4G 目标资源及独立 UAT 尚未完成。
技术方案：[design.md](design.md)。执行与验证：[implement.md](implement.md)。

## 目标与使用者

面向需要对照多份供应商方案/报价的小团队采购评估者、项目协调者或技术选型者，将跨文件查找、摘录、核对口径和整理表格变成可复核的交付流程。角色与频率属于待验证客户假设，当前没有独立试用参与者。

首个完整任务：用户提供一份需求清单及三家供应商资料，确认约十个比较字段，获得比较表、待确认项和可定位的来源；人工审核后用于决策。系统不自动选择供应商、下单或对外承诺。

本方向已由用户选择，架构 v1 已获用户批准并开始实现。阶段切片不表示完整功能、模型质量或商业价值已验证。已有售前问卷功能与历史记录保留，新主线以本任务为准。

## 用户行为范围

| 编号 | 需求 |
| --- | --- |
| R1 组织资料 | 按比较对象、共同需求和文件版本组织材料；显示解析状态及未支持内容 |
| R2 定义清单 | 用户选择/编辑有限字段、类型、比较口径和必需参数，运行前可看到范围 |
| R3 逐项取证 | 在授权来源内提取值及条件，必要时补查；来源缺失、矛盾、不可读或不适用有区别 |
| R4 确定性计算 | 已知数量、单位、期间等前提后完成可复算计算；未知税率/汇率不猜测 |
| R5 稳定执行 | 任务可离开页面继续；单元失败不丢弃其他结果；预算与取消行为可预期 |
| R6 原文复核 | 在结果旁查看原文位置；人工修正和确认留痕，不改写原始生成记录 |
| R7 可交付 | 导出比较表、待确认与来源依据；草稿/复核稿身份明确，未解决项不能隐藏 |
| R8 更新资料 | 改参数或换资料后只更新受影响范围，旧交付仍可追溯，旧审批不误用于新内容 |
| R9 权限与计量 | 成员只能访问获准材料及其结果；重复请求/恢复不重复业务结算 |
| R10 效果验证 | 完整任务对照包含审阅投入、错误、未知处理及再次使用，扩展材料检验泛化 |

## 首版约束与不在范围内的需求

- 沿用现有单仓库、4C4G 和现有服务；不新增备用服务器或 GPU。
- 支持范围以文本型 PDF、TXT、DOCX 正文/表格和静态 XLSX 为主；无法可靠读取的内容明确提示。精确格式和规模限制见设计。
- 首轮 3 个对象、约 10 字段是开发范围；不是已验证容量。规则/计算字段和事实字段区分。
- 固定一个经验证主路，最多两次模型派发/单元；补查、传输重试共用预算，超过上限明确停止。既有每日额度与权益不因新方向自动扩大。
- 本轮不实现 OCR、任意 Excel 公式重算、宏执行、浏览器代操作、任意代码、自动网页取证、多 Agent 团队或对外发送。
- 无独立参与者时先准备完整试用任务、操作说明、计时与反馈材料；不填造用户收益或付费结论。

## 验收标准

以下为完整产品验收，尚未整体通过。当前工程候选覆盖资料解析、来源分组/快照、固定与有限 Agent 取证、权限、计量、恢复、原文引用、人工审阅、静态导出及跨快照保守复用；具体证据见 implement.md。受控响应证明工程状态机，不替代真实模型质量、目标资源或商业验收。

| 编号 | 可观察验收行为 | 对应需求 |
| --- | --- | --- |
| A1 | 将同名字段分别放在不同供应商材料中，结果与引用不串对象；PDF 页、DOCX 表格、XLSX 单元格可定位 | R1/R3 |
| A2 | 存在无文本扫描页、缺失公式缓存或不支持内容时，UI/导出均提示限制，不声称完整读取 | R1 |
| A3 | 文档明确反证、未找到、资料冲突和不适用得到不同状态；“未找到”保留搜索范围 | R2/R3 |
| A4 | 初次证据不足时可展示一次有依据的补查；仍不足则停止或请求输入，无隐藏第三次调用 | R3/R5 |
| A5 | 输入已知月单价、数量和月份时输出可复算总额；税费未知时不输出伪造含税金额 | R4 |
| A6 | 模型 503、未知超时、Worker 重启、队列重投、页面刷新分别按策略处理，不超预算/重复结算 | R5/R9 |
| A7 | 修改字段形成新结果版本，旧原稿和证据可查；过期 revision 的审核被拒绝 | R6 |
| A8 | 导出包含完整选定范围及失败/未知清单，草稿和复核稿不同；复核不等于所有选项均满足 | R7 |
| A9 | 替换附件会失效此前依赖该来源范围的“未找到”结果；改数量只更新相关计算；旧交付不改写 | R8 |
| A10 | 跨租户、来源权限撤销、文档内恶意指令不能扩大工具权限或绕过审批 | R9 |
| A11 | 冻结候选在未参与调参的不同资料包上验收；记录固定流程与有限 Agent 的质量、用量、延迟 | R10 |
| A12 | 无参与者时完整试用包可供后续独立使用；没有真实反馈前商业收益保持未验证 | R10 |

## 交付与完成边界

本地工程候选已经演示“上传与分组 → 取证/有限补查 → 计算 → 复核 → 导出 → 更新”完整路径，并覆盖失败、恢复、权限和计量。受邀试用前仍须配置受控环境并执行容量/模型门槛；生产发布继续受原商业发布门禁约束。

当前可声明的完成边界只有：工程候选完成、内部验证完成、试用材料就绪。真实模型质量收益、4C4G 生产容量、独立客户 UAT、商业收益和付费验证必须单列，不能与工程闭环混为完成状态。当前参与者为 0；验证包和足球球衣跨领域留出包均未独立评分。
