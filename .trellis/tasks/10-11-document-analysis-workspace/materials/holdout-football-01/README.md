# holdout-football-01 足球球衣采购留出包

这是跨领域泛化留出包，用三件官网足球球衣及各品牌退货政策验证同一多文档工作台是否能处理零售采购资料。它不改变产品主线，也不是足球专用产品。

只把 `upload/` 中七个文件交给系统：共同需求单独分组，Nike、adidas、PUMA 各自的产品页与退货政策分别归到对应对象。按 `manifest.json` 的十字段建立 30 个单元。`reference/`、manifest 和本说明不得上传。

三件商品并非同规格或批量报价：包含 replica/authentic、不同赛季和美国站地区条件。页面没有明确当前价格、币种、批量折扣或送达重庆条件时必须保留缺口，不能用搜索摘要补齐。研究阶段的搜索摘要曾声称 PUMA 退货为 60 天，而抓取的官网正文写 30 天；本包只允许使用抓取正文。

冻结材料另有两个必须保留的抓取缺口：`nike-returns.txt` 没有实际政策正文，`adidas-returns.txt` 是软 404。adidas 商品页仍有有限的 30 天免费退货和定制不可退换信息，但未说明 30 天起算事件。不得用其他页面或常识补齐，也不得把软 404 后的推荐商品价格归到目标球衣。

`reference/review-notes.json` 和同目录说明是助手整理的 30 行审阅底稿，用于扩大试用范围后的独立核验。它们不是金标，不能预填独立审核，不得进入上传或模型上下文；冻结 manifest、原 reference 与 `upload/` 未修改。

该包尚未运行真实模型、未独立标注、未给参与者使用，质量分数为 `null`。公开可读不等于取得再发布许可，仅限本地验证和受邀试用。
