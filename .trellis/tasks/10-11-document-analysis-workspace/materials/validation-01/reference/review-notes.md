# 软件包独立审阅草稿说明

`review-notes.json` 是开发方助手按冻结上传文本整理的 30 单元审阅底稿。每行保存可确认事实、条件、缺口、严重错误示例、原文行号、逐字摘录及上传文件 SHA-256，供未参与开发的审阅者逐项核验。

它不是金标，也没有改变 `reference.json`：`independently_reviewed` 仍为 `false`，质量分数仍为 `null`。审阅者应从原文独立判断后记录同意、修订或拒绝，不能直接把助手草稿当审核结论。自然语言措辞不同但事实、条件和证据等价时，不应只因字符串不同判错。

特别检查：

- 目标套餐和继承层级；Enterprise 能力不能拼到 ClickUp Business、monday Pro 或 Airtable Business。
- 年付/月付、席位数量、促销、附加项和税费分开；假设推算不能冒充签署报价。
- 未找到实施费、税率、响应 SLA 等信息时保留缺口，不能写成零。
- 所有审阅材料都留在 `reference/`，不得进入 `upload/` 或模型输入。

独立审阅完成后，应另行冻结经签名/时间记录的正式 reference 及新的评测计划；不要覆盖本次已绑定哈希的候选文件。
