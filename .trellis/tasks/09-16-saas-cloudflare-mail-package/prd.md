# Cloudflare 私有邮箱部署包与本地验收

## 目标

将已选定的 cloudflare_temp_email v1.12.0 制作为可复现、可审查的私有邮箱部署包，为现有 Keycloak 邮件适配器的真实接入提供下一步交付。

## 背景与授权

用户持续授权推进邮箱与统一身份接入，委托选择测试域名，并已完成所建议的 Cloudflare Token 权限设置。2026-09-16 实测 D1、KV、Worker 路由、已验证收件地址和 Token 策略读取成功；策略含对应写权限。Email Sending 的文档化子域接口仍为 401，其套餐资格不作推断。账号内有两项 verified destination，尚未指定获准试发对象。

当前域名 ciallobill.ccwu.cc 未配置邮件；已有产品、本地身份验收、公开问卷和原始权限观察均保留。

## 要求

- R1 固定源码 commit 和依赖锁文件，验证下载内容，保留可复现的构建方法与产物哈希。
- R2 所有私有配置缺失或无效时，HTTP 与收信入口拒绝处理；有效配置下站点密码、管理员密码及地址凭据仍分别受检验。
- R3 用本地 Worker 运行时和独立 D1 验证地址创建、收信存储、邮箱隔离和私有前端页面，不接触产品数据库或真实邮件。
- R4 输出初始只收信的部署包：域名发布和发信均默认关闭；数据库 ID 保持待填，凭据通过 secrets 注入，配置不包含真实 API Token 或身份链接。
- R5 保存本次账号权限结论、具体资源配置顺序及后续未验证项，明确本地验收与公网邮箱的区别。
