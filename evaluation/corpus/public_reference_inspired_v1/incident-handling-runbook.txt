# Northstar Ledger Incident Handling Runbook

## Classification

An event is an observed condition that may need review but has not been declared harmful to a service.
An incident is a declared service disruption or confirmed security impact that needs coordinated response.

## Response controls

The response lead may isolate the affected workload before root-cause analysis when that action limits continuing harm.
Preserve relevant logs and artifacts before destructive remediation when doing so does not add material risk.
Recovery actions return the documented service to a known-good state and record the decision owner.
